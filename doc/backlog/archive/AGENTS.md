# Backlog archive

Closed epics and tasks are stored here as **historical record only**.

## Agent rules

1. **Do not browse** this folder to discover work. Do not `ls`, glob, or search
   under `doc/backlog/archive/` unless a **non-archived** document already linked
   you to a specific path inside it.
2. **Do not edit** anything under this folder (no content fixes, renames, or
   “cleanup”) unless the user explicitly instructs an archive change.
3. **Do follow** a concrete link from a live doc (`doc/design/`, active
   `doc/backlog/TASK-*`, module `AGENTS.md`, etc.) when you need that historical
   section — then stop; do not wander to sibling archive files.

Active architecture and “where to look” live in `doc/design/` and module
`AGENTS.md` files, not here.

See [doc/AGENTS.md](../../AGENTS.md) Layout and Vault invariants.
